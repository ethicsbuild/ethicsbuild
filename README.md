## Live

### [E.D.A.I. (Ethical Deployment of AI)](https://edai.quest)
Status: prototype. Site live.
A verification model for deployed AI, built around one first principle: a machine that cannot say "I don't know" will say something else instead. One Guardian credential is minted on Hedera mainnet (token 0.0.9375999, July 2025). Two event topics exist with zero events logged. The [State of the Work, September 2026](https://edai.quest/state-of-the-work) says what is built, what was borrowed, and what has not been done; it supersedes an earlier white paper. Code: [edai-hedera-network](https://github.com/ethicsbuild/edai-hedera-network), [edai-landing](https://github.com/ethicsbuild/edai-landing).

### [AI for All](https://www.aiforallapp.com)
Status: coaching practice, taking clients through the intake. App in development, not public.
Teaching adults to use AI with verification habits rather than trust. Corporate pilot and individual coaching.

### [Integrity Gatekeeper](https://www.integritygatekeeper.com)
Status: live, one reviewer.
Twenty-two questions, answered alone, read by one person. Not a hiring instrument; an attempt to understand people. Every promise on its disclosure screens is kept by the code. The [2025 original](https://www.integritygatekeeper.com/mirror/) is kept as the memory of inception.
